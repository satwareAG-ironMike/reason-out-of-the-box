## Abstract (condensed)
Establishes the empirical baseline for the ICL-as-algorithm line: transformers trained
from scratch can learn in-context from input-output pairs of simple function classes,
matching or exceeding well-fitted baselines, entirely at inference time without any
parameter updates.

## Key findings
- In-context learning is formalized as conditioning on a prompt of input-output pairs
  plus a query, with output generation "only at inference time without any parameter
  updates to the model" (abstract).
- Trained transformers approach or exceed the performance of well-fitted learning
  algorithms on the studied function classes; GPT-3 shows the same qualitative ability
  at scale. (Findings rest on the verified abstract; no full-text quotes in this
  entry.)
- The paper is the standard reference both issue #1 and the Akyurek 2023 construction
  paper build on; the Akyurek full text cites it as the empirical ICL baseline.

## Relevance to core question
Shows function-class learning is implementable in a forward pass, but always with
demonstrations present in the prompt - "in-context", not out of the box. Together with
Akyurek 2023 it defines the ceiling the H1 experiment probes: what remains when the
demonstrations and the task-family training are both removed. (Issue #1 listed this ID
as "ICL as gradient descent / Akyurek"; the ID is Garg et al. - corrected here, with the
actual Akyurek paper added as 2211.15661.)
