## Abstract (condensed)
Asks how in-context learning works on a restricted class of problems (linear
regression): which learning algorithms transformer decoders can implement in their
forward pass, and which algorithms trained models actually implement. Provides
constructions showing transformers can implement steps of gradient descent and
closed-form ridge regression, and empirical evidence on what trained predictors match.

## Key findings (verified from full text)
- Constructions: for d-dimensional regression, a transformer with O(d) hidden size and
  constant depth can implement a single step of gradient descent on the least-squares
  objective; with O(d^2) hidden size and constant depth it can update a ridge
  regression solution with one new observation. n steps require n times more layers.
- Trained in-context learners: predictions are closely matched by candidate predictors
  (gradient descent, closed-form, Bayes) and transition between them as model depth and
  training noise vary, behaving like Bayesian predictors at large hidden size and
  depth; hidden-state requirements for ridge-like behavior are smaller than the
  constructions need, suggesting ICL finds more efficient implementations.
- Intermediate quantities of learning algorithms (parameter vectors, moment matrices)
  can be decoded from hidden activations.
- Authors' framing: "some in-context learning appears to involve familiar algorithms,
  discovered and implemented by transformers from sequence modeling tasks alone."
- Peer-review: ICLR 2023 (OpenReview forum 0g0X4H8yN4I).

## Relevance to core question
The formal frame for "what algorithm could ICL implement": real learning algorithms are
implementable in a forward pass and do emerge under sequence-modeling training - but
emergence here is from training on the task distribution, and behavior is measured
given demonstrations in context. Bounds what demonstrations can identify and what the
thesis H1 experiment should expect from zero-demonstration base models. (Note: issue #1
listed 2208.01066 for this line; that ID is Garg et al. 2022, added separately.)
