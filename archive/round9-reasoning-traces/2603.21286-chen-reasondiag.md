## Abstract (condensed)
Presents ReasonDiag, an interactive visualization system for diagnosing errors in
chain-of-thought traces. An error detection pipeline combines external fact-checking
(retrieval-augmented evidence) with symbolic formal logical validation (LLM translation
of steps into Z3/SMT constraints) to flag step-level factual and logical errors; arc and
node-link diagrams expose reasoning-step distributions, premise dependencies, and error
propagation. Evaluated technically and with 16-participant user interviews.

## Key findings (verified from full text)
- Pipeline: (1) premise tree generation (step segmentation, functional role
  classification, verifiability, premise-conclusion relations); (2) factual error
  detection via retrieval-augmented external evidence; (3) logical error detection by
  translating natural-language steps into Z3-checkable formulae - any unstated
  assumption or logical leap yields an unsatisfiable result.
- Evaluation dataset: 13 Deltabench CoT traces segmented into 2,030 sentences, 1,171
  verifiable, annotated by a 10-person pool (9 PhD); released on HuggingFace
  (CoTDiagnosis/DeltaBench_CoT_Diagnosis).
- Sentence-level detection with GPT-5 for all methods: ReasonDiag precision 0.306,
  recall 0.801, F1 0.386; BIG-Bench prompt baseline 0.432/0.658/0.470; DeltaBench
  prompt 0.051/0.041/0.044. Recall prioritized by design; the authors state low
  precision (best 0.432 across methods) shows human verification remains necessary -
  which is the interface's role.
- 16-participant interviews plus 2 case studies: users better understand traces, locate
  erroneous steps, and determine root causes.
- Peer-review: Computer Graphics Forum (Eurographics Visualization) 45(3), 2026.

## Relevance to core question
Peer-reviewed confirmation that step-level reasoning-error detection requires machinery
outside the model: retrieval-grounded fact-checking and an external SMT solver, with
humans closing the precision gap. Validates the archive's engineering-not-native
pattern for verification (cf. Latent Veracity Inference, Huang et al.). Silent on
out-of-the-box reasoning; a tool and evaluation datapoint.
