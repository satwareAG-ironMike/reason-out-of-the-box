## Abstract (condensed)
Presents code that procedurally generates examples for the ARC training tasks: for each
of the 400 tasks, an example generator implementing the task's transformation logic was
created, reverse-engineering the assumed underlying distribution of examples and
sampling from it.

## Key findings
- One generator per ARC training task (400 total), each following the transformation
  logic of the original examples; the goal is to cover as large a space of possible
  examples per task as reasonable (abstract).
- Enables evaluation and training beyond the fixed published task instances - the
  contamination-safety property the archive's Condition 2 requires (novel items from
  held-out seeds).

## Relevance to core question
Direct infrastructure for the thesis ARC-style task family: generators with per-task
transformation logic allow procedurally novel items whose instances postdate any
training cutoff. Preprint, tooling only; no reasoning claim.
