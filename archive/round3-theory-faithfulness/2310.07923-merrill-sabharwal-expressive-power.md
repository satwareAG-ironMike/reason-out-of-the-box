## Abstract (condensed)
Formalizes how much computational power chain-of-thought steps add to decoder-only
transformers. Fixed-depth transformers are limited to the circuit class TC0 (highly parallel
computation); each CoT step adds sequential power. With t(n) CoT steps, expressivity reaches
determined time t(n): linear steps give certain regular languages, polynomial steps reach
polynomial time under assumptions.

## Key findings (verified from full text)
- **Single forward pass = TC0**: a bare transformer provably cannot express inherently
  sequential problems (graph connectivity, iterated composition) regardless of width.
- CoT is not a convenience; it is the mechanism that purchases sequential depth. One token
  of generated text = one unit of extra computation.
- Implication: any "reasoning" a base model does in one pass must be amortized/parallel
  approximation, not execution of a general sequential procedure.

## Relevance to core question
**Formal argument against strong out-of-the-box reasoning** in a single pass - and a formal
argument *for* why elicited multi-token reasoning is necessary. Biology escapes this ceiling
via native recurrence; LLMs must pay per generated token.
