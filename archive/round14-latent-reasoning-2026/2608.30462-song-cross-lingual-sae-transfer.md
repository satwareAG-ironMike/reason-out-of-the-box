## Abstract (condensed)
LLMs show large cross-language performance variation on semantically equivalent tasks.
Existing analyses attribute the gap to pretraining data, tokenization, or benchmark
coverage. This paper tests a complementary hypothesis: high-resource languages (HRLs)
more reliably elicit latent computations useful for task-specific (mathematical)
reasoning, while lower-resource languages (LRLs) under-activate them despite the same
task. It introduces a mechanistic intervention framework using sparse autoencoders over
residual-stream activations to isolate task-relevant latent features enriched in
successful HRL reasoning, build steering directions from them, and inject them during LRL
inference. Suppressing the features should impair source-language reasoning; activating
them should partially recover target-language reasoning beyond random and non-task
controls.

## Key findings (from abstract)
- Reframes some cross-lingual reasoning gaps as failures of mechanism elicitation rather
  than capability absence.
- Sparse autoencoder steering over residual-stream activations is the causal test:
  feature suppression impairs, feature activation partially restores, target-language
  reasoning - a causally testable route without translation, fine-tuning, or changing the
  user-facing language.

## Relevance to core question
Assessment: mechanistic H0-b evidence. It provides the causal machinery (SAE steering)
for the claim that the reasoning computation is present but un-elicited in some regimes,
strengthening the "capability latent, elicitation is the bottleneck" consensus. Fails
out-of-the-box: the transfer is a trained SAE steering intervention, and the tasks are
not procedurally novel post-cutoff. Meets none of the five acceptance conditions.
Overall verdict unchanged.
