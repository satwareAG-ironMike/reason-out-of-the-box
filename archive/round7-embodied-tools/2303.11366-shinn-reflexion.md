## Abstract (condensed)
Agents reinforce via linguistic feedback instead of weight updates: after a failed trial, the
agent verbally reflects on the environment's feedback signal, stores the reflection in an
episodic memory buffer, and conditions the next attempt on it. Gains on decision-making
(AlfWorld), reasoning (HotPotQA), and programming (HumanEval 91% pass@1).

## Key findings
- Learning without gradient updates: memory of verbalized failures acts as the policy
  improvement step.
- Works only with an **external signal** (unit tests, environment success flags) to
  reflect on - self-reflection without ground truth would inherit the round-5 failure.

## Relevance to core question
**The bridge between round 5 (LLMs cannot self-correct) and round 7 (agents improve)**:
the missing ingredient is an environment that says "wrong." Given that, verbal memory of
mistakes compounds into competence - stored learnings, in text.
