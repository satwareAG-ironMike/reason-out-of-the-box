## Abstract (condensed)
Embodied social agents that learn for a lifetime inside a community in a 3D open world,
accumulating experience through everyday visual observations and social interactions. Core:
a structured long-term multimodal memory - name-centric semantic memory plus spatiotemporal
episodic memory.

## Key findings
- The "herd" component made explicit: knowledge is acquired *socially* (interactions with
  other agents and humans) and stored in typed memory structures.
- Memory retrieval is integrated with foundation models for decision-making at lifelong
  timescales.

## Relevance to core question
**The herd as an external memory and learning channel**: agents that live in a community
acquire knowledge no single model carries - social learning as a complement to pretraining.
