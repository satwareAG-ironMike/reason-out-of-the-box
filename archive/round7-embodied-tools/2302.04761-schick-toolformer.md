## Abstract (condensed)
A model teaches itself to call external APIs (calculator, QA, search, translation, calendar)
via a self-supervised objective: it annotates text with candidate API calls, keeps only
calls whose results reduce next-token loss, and fine-tunes on them. A few demonstrations
per API suffice; zero-shot downstream performance improves substantially.

## Key findings
- Tool use can be **self-discovered** by the loss criterion "does this call help me
  predict?" - the body is adopted because it makes the brain's job easier.
- Small tool-using models beat much larger tool-less ones on arithmetic and factual tasks:
  offloading to tools substitutes for scale.

## Relevance to core question
**Origin paper for "brain + body"**: the LLM does not need to compute what a calculator
computes; it needs to know when to reach for it. Reasoning-by-delegation is a legitimate
strategy - the same one humans use.
