## Abstract (condensed)
Runs an autonomous corpus-to-manuscript pipeline over 11,083 condensed-matter physics arXiv
papers, producing a submission-grade manuscript (altermagnetic piezomagnetism). Core
problem: in physical science, execution provides no ground truth; calibration must come
from external literature anchors.

## Key findings (verified from full text)
- Failure mode: "Without external anchor enforcement, agents default to internal-prior
  generation, producing confident plausible outputs that cannot be verified by execution
  alone."
- **Access is not grounding**: the pipeline consulted literature 2,162 times over 14
  channels, yet in the no-pilot ablation the agent picked a recipe 2.7x below the published
  reference and "the comparison 0.066 vs. 0.176 was never written" across four review
  cycles. Adversarial review alone did not catch it.
- Operational definition of grounding: "structurally enforced literature confrontation at
  calibration checkpoints" - forced numerical comparison against published values, not
  citation. The canonical run tracked seven anchors (4 PASS, 3 caveat-flagged); 15 catches
  via four mechanisms; human intervention nine operational events, none scientific.
- Stated limits: one research direction, no head-to-head vs other frameworks,
  multi-trial variance unquantified (~6 days wall time per run).

## Relevance to core question
**Bridges the archive's two halves with a mechanism**: LLMs cite the herd's knowledge
fluently but do not confront it unless architecture forces the comparison. Validation
must be built as a checkpoint, not hoped for as a habit. Single-run study: directional
evidence, not statistics.
