## Abstract (condensed)
Introduces LRLL: an LLM-based lifelong-learning robot agent that continuously grows its
own skill library for manipulation tasks of increasing complexity, using four mechanisms:
memory curation, experience accumulation, skill library updating, and VLM-grounded
verification.

## Key findings
- Addresses Voyager-style limitations in the physical domain: hand-crafted prompts and
  static skill libraries cap the addressable task range.
- Skills verified through a vision-language model before entering the library - perception
  gates what the body stores.

## Relevance to core question
**Body-side version of the skill-library idea**: the "brain" accumulates competence by
writing code the "body" has physically validated. Stored learnings = tested code, echoing
the git-as-memory framing.
