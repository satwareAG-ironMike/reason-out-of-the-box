## Abstract (condensed)
First LLM-powered embodied lifelong-learning agent (Minecraft): explores continuously,
acquires skills, makes novel discoveries without human intervention via (1) automatic
curriculum, (2) an ever-growing **skill library of executable code**, (3) iterative
prompting that incorporates environment feedback, execution errors, and self-verification.

## Key findings (verified from full text)
- 63 unique items discovered in 160 prompting iterations: 3.3x more novel items, 15.3x
  faster to the wooden-tool tech-tree milestone, 2.3x longer map traversal than prior
  auto-curriculum agents.
- The skill library is the memory of the body: learned behaviors are stored as runnable
  code and retrieved compositionally - "stored learnings" in the project's framing.
- Self-verification is done **by querying the game state**, not by the LLM judging itself:
  grounding the check in the environment.

## Relevance to core question
**The canonical demonstration of the embodiment hypothesis**: LLM (brain) + API-controlled
world (body) + environment feedback (validation) yields open-ended novel capability
(discoveries) that the base LLM alone does not exhibit. Novelty here comes from the loop,
not the model.
