## Abstract (condensed)
25 LLM-driven agents inhabit a sandbox town (Smallville). Architecture: a natural-language
memory stream, reflection (periodic synthesis of memories into higher-level inferences), and
planning. Emergent social behaviors: information diffusion, relationship formation, and
coordination (a spontaneously organized Valentine's party).

## Key findings
- Emergent group behavior arises from individual agents with memory + reflection + the
  ability to communicate - the herd produces outcomes no single agent planned.
- Ablations: removing reflection or memory retrieval degrades believability - the
  memory/reflection loop, not the base LLM, carries the social competence.

## Relevance to core question
**The herd, instantiated**: communication among agents plus durable memory produced
collective novelty (the party) that was not in any prompt. Evidence that "a herd to
communicate and learn" adds a layer of capability above the individual model - with the
caveat that this is behavioral believability, not verified reasoning.
