## Abstract (condensed)
Proposes that pretrained LMs derive new conclusions by aggregating indirect reasoning paths
seen at pretraining time, formalized as random walk paths on knowledge/reasoning graphs.
Experiments on KG and CoT datasets support the view that weighted sums of relevant random
walk path probabilities explain LM reasoning.

## Key findings
- Explains the *mechanism by which pretraining produces apparent reasoning*: composition of
  path fragments, not execution of a learned inference engine.
- Directly relevant to the debate: supports the "reasoning = composed retrieval" reading,
  while still showing why compositional generalization beyond seen paths is hard.

## Relevance to core question
**Complicates (negative-leaning).** If reasoning is path aggregation, then "out-of-the-box"
performance is bounded by which paths pretraining contained - supporting the skeptic case
and predicting exactly the Faith-and-Fate-style collapse on novel depth.
