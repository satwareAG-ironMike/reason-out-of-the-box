## Abstract (condensed)
Shows that LMs given only a single trigger phrase - "Let's think step by step" - with zero
task examples (Zero-shot-CoT) substantially improve multi-step reasoning on arithmetic
(MultiArith: 17.7% -> 78.7%), symbolic, and other logical reasoning tasks, using off-the-shelf
GPT-3, no fine-tuning, no task-specific prompts.

## Key findings (verified from full text)
- A single generic verbal trigger unlocks step-by-step solving in a model that was never
  trained on reasoning traces specifically - the "elicitation" story in its purest form.
- Two-stage: reasoning extraction then answer extraction, still zero exemplars.
- Failure modes remain: ordering tasks, small-model collapse (works poorly below ~100B,
  motivating the "emergence" scale story).

## Relevance to core question
**Supports (partially).** The reasoning computation was clearly already in the pretrained
weights; the prompt only points at it. Counterpoint: "think step by step" is still a human
prior; performance was far from ceiling, and later contamination work (GSM1k) qualifies the
benchmark numbers. NeurIPS-peer-reviewed.
