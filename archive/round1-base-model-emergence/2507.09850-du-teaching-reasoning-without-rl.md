## Abstract (condensed)
Asks whether long chain-of-thought can be induced in a base model using only prompting or
minimal tuning. Fine-tunes Qwen2.5-32B base with just **20 long CoT examples** from QwQ-32B;
the result outperforms the 72B Qwen2.5-Math-Instruct. Human-written CoT, even curated, does
not fully match reasoning-model traces.

## Key findings
- 20 examples unlock long-CoT behavior: reasoning behavior sits barely below the surface in
  base models - "activation" rather than "teaching".
- But: it never succeeds with zero examples, and expert reasoning-model traces carry latent
  qualities that plain prompting cannot reproduce. RL/distillation remains the reliable path.

## Relevance to core question
**Bipartisan evidence.** Strengthens "capability is latent" (20 examples suffice) while
confirming the skeptical framing (0 examples is not enough; pure out-of-the-box long
CoT has not been demonstrated even in 2025).
