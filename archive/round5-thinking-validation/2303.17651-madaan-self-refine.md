# Self-Refine: Iterative Refinement with Self-Feedback

| Field | Value |
|-------|-------|

| Authors | Aman Madaan et al. (CMU, Allen Institute for AI) |

## Abstract (condensed)
A single LLM acts as generator, feedback provider, and refiner in a loop: generate, critique
its own output, revise; repeat ~20% average absolute improvement across 74 tasks (dialogue,
code, math, sentiment, etc.).

## Key findings
- Gains concentrate on tasks where the feedback criterion is **externally checkable in the
  prompt or trivially verifiable** (e.g., concept coverage, code executability, tone).
- On reasoning-heavy tasks, later work (Huang et al., ICLR 2024, round 5) showed reported
  gains largely vanish once the initial prompt carries the same explicit criteria - the
  loop added instruction detail, not verification.
- Each refinement iteration is another sample from the model's distribution; no new
  evidence enters the loop.

## Relevance to core question
**The canonical "LLM validates ideas by talking to itself" scheme - and its boundary.**
Self-refinement improves *form* reliably and *substance* only where the model already had
the checking criterion in-distribution. Genuine validation requires evidence external to the
model's own distribution.
