# CRITIC: Large Language Models Can Self-Correct with Tool-Interactive Critiquing

## Abstract (condensed)
Framework where LLMs validate and revise outputs using external tools: search engines,
code interpreters, calculators. The model critiques its initial answer, then uses tool
results to revise. Consistent gains on complex reasoning and factuality benchmarks.

## Key findings
- Self-correction works when the critique is **grounded in tool feedback** - external
  evidence enters the loop, unlike Self-Refine.
- LLMs alone make unreliable critics; with tools, critique becomes falsification
  (run the code, check the fact).
- Contrasts directly with Huang et al. (ICLR 2024): the failure of intrinsic self-correction
  and the success of tool-grounded correction isolate *where* validation ability lives.

## Relevance to core question
**Positive result on validation, with the mechanism identified.** LLMs can validate ideas
only through contact with external ground truth. This matches the biology analogy: humans
also validate ideas against the world (experiments, peers), not by introspection alone.
