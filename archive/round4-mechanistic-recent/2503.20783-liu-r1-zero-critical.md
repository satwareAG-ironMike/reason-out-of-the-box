## Abstract (condensed)
Critically decomposes R1-Zero-style training into (a) base model properties and (b) the RL
algorithm (GRPO). Analyzes DeepSeek-V3-Base, Qwen2.5 family, and proposes Dr. GRPO, an
unbiased fix for GRPO's length/optimization bias.

## Key findings (verified from full text)
- "**All base models already possess math-solving capability prior to RL.**"
- "**Nearly all base models already exhibit the 'Aha moment', including DeepSeek-V3-Base.**"
  - the reflection behavior famously attributed to RL exists pre-RL.
- Qwen2.5-Math base answers at high accuracy **without any template** (immediate ~60%
  improvement when discarding templates); applying the R1 template *destroys* the capability,
  which RL then reconstructs: "we should be more conservative in claiming the huge gains
  brought about by pure RL."
- GRPO's response-level length bias confounds claims of "emergence of long CoT": GRPO keeps
  lengthening wrong responses; Dr. GRPO removes the bias.
- "Even a small and completely o.o.d. question set could induce the reasoning ability equally
  well, by **reinforcing useful reasoning behaviors instead of infusing new knowledge**."

## Relevance to core question
**The key 2025 ablation paper.** RL is shown to be an *elicitor and amplifier* of pre-existing
competence, not a creator. This substantially strengthens the claim that reasoning-relevant
capability is installed by pretraining - while simultaneously confirming that without
elicitation (template/RL/decoding) it does not express. Neither side of the debate gets a
clean win; the "out of the box" question becomes "out of which box, elicited how."
