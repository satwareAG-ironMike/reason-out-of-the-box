# Adversarial review record - round 14 (2026-09-28)

Scope: the 15 arXiv entries in [archive/round14-latent-reasoning-2026/](../../archive/round14-latent-reasoning-2026/),
reviewed against raw arXiv abstract pages. Method follows
[docs/agent-execution.md](../agent-execution.md) section 5 (verifier independence, per-claim confrontation,
dispositions "accepted / qualified / rejected"). The reviewer is a separate pass from the original
archiving agent; no entry file was modified by this review.

## Method

- Each entry file was read in full (raw markdown).
- Each arXiv abstract page (arxiv.org/abs/ID) was fetched fresh on 2026-09-28 and the entry's
  quoted numeric claims were compared against the abstract text verbatim.
- Claims were checked for: value equality, unit / direction, bounded wording ("up to"),
  benchmark names, and version / date / venue metadata.
- Quantitative claims are checked exactly; qualitative / label claims are checked for string match.
- No full text was read for this round (all entries are abstract-level; no [FT] marker).
