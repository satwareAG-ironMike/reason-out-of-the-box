# Verification and review record - round 16 (2026-10-14)

Scope: the 13 entries in [archive/round16-insect-sentience/](../../archive/round16-insect-sentience/),
ingested with per-claim verification against primary records during the same session

rejected"). All entries are abstract-level (full text not read; no `[FT]` marker).

## Method

- Metadata (title, authors, venue, volume, pages, year, ISSN) verified against the
  Crossref REST API (`api.crossref.org/works/<DOI>`) for all 13 records.
- Abstracts fetched from PubMed eutils (`efetch.fcgi?db=pubmed&rettype=abstract`) for the
  6 PMID entries; reconstructed from OpenAlex `abstract_inverted_index` for the 6 entries
  without a PubMed record; from the arXiv export API for 2609.16247 (authors, abstract,
  v1/v2 dates).
- The 6 entries without arXiv/PubMed/PhilPapers IDs (Animal Behaviour x4, Animal Sentience,
  Phil Trans B) are covered by the DOI-only provenance rule
  added test-first in this round: selftest RED commit `75d28a7` (DOI case fails until
  support lands), GREEN commit `bcb9c2f` (checker accepts `| DOI |` fields and enforces the
  DOI local part in the filename; `archive/AGENTS.md` provenance rule extended).
- PhilPapers returned HTTP 403 to direct fetches in this session; no entry relies on it.
  Semantic Scholar and bioRxiv APIs rate-limited (429); the bioRxiv preprint ID for the
  critique is carried from the publisher abstract, not fetched.
- Quantitative claims are checked exactly against the fetched abstract text; quoted
  conclusion wording is checked as a string match and attributed as "abstract wording" in
  the entry.
