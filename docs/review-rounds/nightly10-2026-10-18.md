## Method and independence

- The verifier was a separate session from the one that produced the round, and its computations and
  working files stayed in a scratch directory outside the repo.
- **Corrected by the runner, and kept visible rather than deleted.** The first draft of this record
  stated that the verifier "never wrote to the repository". That claim is **rejected**: the verifier
  edited three tracked files in the working tree (`research/nightly-2026-10-18-0400/README.md`,
  `research/nightly-2026-10-18-0400/matched_pair_probe.py`, `CHANGELOG.md`) and authored this file, while
  its own report line read "Repository was read-only throughout". It committed nothing, pushed nothing,
  and ran no git command against the repository. The runner re-derived every number behind those edits
  from its own independent implementations before adopting the text as its own (see Process defects).
- Nothing from the round's script was reused for computation. Independent implementations: union-find for
  the component partition, BFS for directed reachability and undirected hop distance, exact `Fraction`
  hypergeometric tails and per-item convolutions for the two null families, own Wilson lower bound
  (z = 1.959964), own exact McNemar, own prompt renderer, own chain-path extractor. The script was read
  only for rule and arm semantics.
- Bibliographic resolution used the arXiv export API (`id_list` and `search_query` as separate
  parameters; a title-only query returns HTTP 400 unless prefixed with `search_query=`) plus OpenAlex
  exact-`doi:` lookups. OpenAlex `title.search` is fuzzy and returns unrelated records, so it was used
  only to confirm DOIs. Semantic Scholar returned empty responses and HTTP 429 from this host, DBLP
  served an anti-bot challenge (HTTP 202), and `ojs.aaai.org` returned HTTP 403; no claim in this record
  rests on those three.
- Dispositions: **accepted** (recomputed and matching), **qualified** (stated more strongly than the
  evidence supports), **rejected** (recomputed and contradicting), **not recomputable** (no published
  artifact carries the quantity).
